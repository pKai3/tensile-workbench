# Tensile Workbench 1.0.3

- Faster CSV imports and lighter interactive curve previews for large datasets.
  Calculations and exported results retain their original resolution.
- Interactive plots now follow Light/Dark, including specimen inspectors,
  group curve reviews, yield-fit grids and Calc–Instron comparisons.
- Two-column legends with wrapped labels in interactive output plots.
- Prevent a white flash while a dark plot is preparing, with a five-second
  fallback if theme setup stalls. Charts start loading before you scroll to them.
- Move protection now sits immediately above Sample group order.
- Future updater releases are published automatically after the test suite
  and Windows/Mac update checks pass.

Use **Check for updates → Install update and restart** in the desktop app.
Saved analyses, specimen overrides, data and output folders are preserved.
