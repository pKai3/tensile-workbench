# Tensile Workbench — next update

- Edit all selected groups’ labels and colours together in one scrollable popup,
  with a single Apply changes action and individual palette-colour resets.
- Open it from the illustrated button beside Group order or a compact shortcut
  beside the plot layout controls. Both use the same multicolour tag icon.
- Follow each group’s plot colour through the sample selector, Summary,
  selectable Summary, Specimens and review views.
- Show custom labels in data views while retaining the original group IDs.
  Applied labels and colours refresh the data views without changing calculated values.

Use **Check for updates → Install update and restart** in the desktop app.
Saved analyses, specimen overrides, data and output folders are preserved.
